### How this list works

- A script checks the career sites of 50+ employers every day (Greenhouse, Lever, Ashby, SmartRecruiters, Workday and Amazon job feeds) and keeps early-career tech roles based in Australia.
- 🆕 marks roles first seen in the last 7 days. Links go straight to the employer, not a job board.
- When an ad comes down it moves to **Closed roles**. Closed roles are cleared each January.
- Want a company added? [Open an issue](https://github.com/shoaib-kk/Australia-Tech-Internships/issues/new?template=add-company.yml). Want to run it yourself? See [how it works](docs/HOW_IT_WORKS.md).

<sub>Not affiliated with any employer. Always check eligibility and closing dates on the employer's site.</sub>
